## 3. 前端页面文件位置（重点）

**位置：`src/app/`，按业务域一级分目录，每个目录下放一个 `page.tsx`**

| 前端域 | 路径 | 说明 |
|---|---|---|
| ERP 桌面端 | `src/app/{sales,purchases,inventory,finance,customers,products,reports,settings,pos,approvals,...}` | 主 ERP，使用 `ErpWorkspaceShell` 全局壳 |
| 员工手机 H5 | `src/app/mobile/` | 独立 `layout.tsx` + `MobileShell`，含 viewport 适配 |
| C 端商城 | `src/app/mall/` | 首页、购物车、结算、订单、商品详情，`_components/` 存页面私有组件 |

三个关键约定：

| 文件类型 | 位置 | 数量 |
|---|---|---|
| 页面 | `src/app/**/page.tsx` | 195 |
| 布局 | `src/app/layout.tsx`（根）、`src/app/mobile/layout.tsx` | 2 |
| 后端接口 | `src/app/api/**/route.ts` | 354 |
| 客户端组件 | `"use client"` 的 `.tsx` | 139 |
| 私有组件 | 同级 `_components/`（下划线前缀，不参与路由） | — |
| 页面样式 | 与页面同名 `*.module.css`（如 `mall/mall-home.module.css`） | — |

**共享组件在 `src/components/`**：`erp-*` 前缀为 ERP 基础件（表格、单据壳、选择器、弹层），`employee-mobile/` 为手机端专用，`前端组件库/` 是按「基础控件 / 业务功能 / 单据结构 / 业务模板」编号的中文设计系统目录（如 `桌面端/02-业务功能组件/强表格/明细强表格`）。

## 4. 需要注意的点

- **没有独立前端工程**（无 Vite、CRA、`pages/`），前后端由同一 Next 项目承载；`apps/*` 是纯服务端 TypeScript。
- **仓内无微信小程序源码**（无 `.wxml` / `app.json` / `project.config.json`），只有 H5 端与小程序后端 API（`.env.example` 也标注 "employee H5 source backup"）。
